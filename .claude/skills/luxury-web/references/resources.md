## Шрифты

**Проверяй кириллицу до того, как предложишь шрифт.** Команда — в SKILL.md.

| Ресурс | Чем полезен |
|---|---|
| [Google Fonts](https://fonts.google.com) | 1500+ семейств, единственный шрифтовой хост, разрешённый CSP артефактов. Фильтр по кириллице есть в интерфейсе |
| [Fontshare](https://www.fontshare.com) | Качественные бесплатные шрифты Indian Type Foundry. Много подходящих для люкса, но кириллица редко |
| [Uncut.wtf](https://uncut.wtf) | Современная open-source типографика, много характерного |
| [Atipo Foundry](https://www.atipofoundry.com) | Pay-what-you-want, уровень платных фаундри |
| [Pangram Pangram](https://pangrampangram.com) | Бесплатные шрифты премиальной фаундри |
| [Free Faces](https://www.freefaces.gallery) | Кураторская галерея — быстро посмотреть, что вообще бывает |
| [Open Foundry](https://open-foundry.com) | Отобранные open-source гарнитуры |
| [Velvetyne](https://velvetyne.fr) | Экспериментальные — для смелых решений |
| [Lost Type](https://www.losttype.com) | Pay-what-you-want фаундри |
| [Font Squirrel](https://www.fontsquirrel.com) | Всё коммерчески свободно, лицензии проверены |
| [Fontsource](https://fontsource.org) | Ставить open-source шрифты через npm |
| [Google Webfonts Helper](https://gwfh.mranftl.com) | Скачать Google-шрифт и захостить у себя — когда нужен офлайн или без внешних запросов |
| [Fontesk](https://fontesk.com), [Befonts](https://befonts.com), [1001 Fonts](https://www.1001fonts.com), [FontSpace](https://www.fontspace.com), [DaFont](https://www.dafont.com) | Большие архивы. **Проверяй лицензию каждого файла** — много «только для личного использования» |

Осторожно с DaFont и FontSpace: там много шрифтов, которые нельзя использовать коммерчески. Для клиентского сайта бери с Google Fonts, Fontshare, Font Squirrel или Fontsource.

## Фотографии

Для люкса главное — не количество, а отсутствие «стокового» вида. Улыбающиеся люди в офисе и рукопожатия убивают премиальность мгновенно.

| Ресурс | Чем полезен |
|---|---|
| [Unsplash](https://unsplash.com) | Самая большая база, лучшая по качеству. Интерьеры, архитектура, тревел — то, что нужно чаще всего |

| [Kaboompics](https://kaboompics.com) | Интерьеры и лайфстайл — сильная сторона для недвижимости и отелей |
| [Life of Pix](https://www.lifeofpix.com) | Высокое разрешение, много атмосферных кадров |
| [Picjumbo](https://picjumbo.com) | Свободно для коммерции |
| [Negative Space](https://negativespace.co) | Много воздуха в кадре — хорошо ложится под текст |
| [Magdeleine](https://magdeleine.co) | Отбор вручную, ежедневно |
| [New Old Stock](https://nos.twnsnd.co) | Винтаж из public domain — для брендов с историей |
| [Rawpixel](https://www.rawpixel.com) | Плюс public-domain живопись и графика |
| [Openverse](https://openverse.org) | Поиск по 800M+ изображений со свободными лицензиями |
| [The Stocks](https://thestocks.im) | Агрегатор — искать сразу по всем банкам |
| [Lummi](https://www.lummi.ai) | Бесплатные ИИ-отобранные изображения и фоны |
| [Generated Photos](https://generated.photos) | ИИ-лица — когда нужен портрет без прав на реального человека |
| [Pixabay](https://pixabay.com), [Burst](https://www.shopify.com/stock-photos), [StockSnap](https://stocksnap.io), [ISO Republic](https://isorepublic.com), [Pikwizard](https://pikwizard.com) | Дополнительные банки |

## Видео для фона

Полноэкранное видео в первом экране — самый быстрый способ поднять восприятие сайта. Требования: короткая петля 8–15 секунд, без резких движений, тёмное или с местом под текст, обязательно `poster` и сжатие до 3–5 МБ.

| Ресурс | Чем полезен |
|---|---|
| [Coverr](https://coverr.co) | Сделан специально под видеофоны сайтов — лучший старт |
| [Mazwai](https://mazwai.com) | Кинематографичные кадры, отбор вручную |
| [Pexels Videos](https://www.pexels.com/videos) | Большая база, хорошее качество |
| [Mixkit](https://mixkit.co) | Видео, музыка и шаблоны |
| [Dareful](https://dareful.com) | 4K, лицензия CC-BY |
| [Motion Places](https://www.motionplaces.com) | Тревел и локации — под консьерж, отели, недвижимость |
| [Videvo](https://www.videvo.net), [Pixabay Videos](https://pixabay.com/videos), [Life of Vids](https://www.lifeofvids.com), [Vidsplay](https://www.vidsplay.com), [Splitshire](https://www.splitshire.com) | Дополнительно |

## Иконки

Для люкса берём тонкие линейные наборы с равномерным штрихом. Заливные и цветные иконки почти всегда удешевляют.

| Ресурс | Чем полезен |
|---|---|
| [Lucide](https://lucide.dev) | 1400+, тонкая линия, ровный штрих — рабочая лошадка |
| [Phosphor](https://phosphoricons.com) | Несколько толщин, включая очень тонкую — самый «дорогой» из бесплатных |
| [Iconoir](https://iconoir.com) | 1500+, лицензия вообще не требуется |
| [Untitled UI Icons](https://www.untitledui.com/icons) | 1100+ чистых линейных |
| [Teenyicons](https://teenyicons.com) | Минимальные 15×15 — для мелких подписей |
| [Radix Icons](https://www.radix-ui.com/icons) | Чёткие 15×15 |
| [Tabler](https://tabler.io/icons) | 5000+, MIT |
| [Heroicons](https://heroicons.com) | От команды Tailwind |
| [Iconify](https://iconify.design) | 200 000+ из 150 наборов через один API — когда ищешь конкретный символ |
| [SVG Repo](https://www.svgrepo.com) | 500 000+ векторов |
| [Simple Icons](https://simpleicons.org) | Логотипы брендов и соцсетей |
| [Akar](https://akaricons.com), [Feather](https://feathericons.com), [Remix](https://remixicon.com), [Boxicons](https://boxicons.com), [System UIcons](https://systemuicons.com) | Дополнительно |

Для узкой темы (яхта, джет, бронеавтомобиль) готовой иконки часто нет — рисуй SVG вручную, 24×24, `stroke-width` 1–1.2, `fill:none`. Единый штрих важнее детализации.

## Иллюстрации и 3D

**Плоские векторные иллюстрации (unDraw, Humaaans, Open Peeps) в люксе не используем** — это визуальный язык SaaS и стартапов, он мгновенно снижает восприятие цены. Оставлены здесь на случай, если проект окажется не люксовым.

| Ресурс | Когда пригодится |
|---|---|
| [Spline](https://spline.design) | 3D в браузере — единственный из раздела, который реально годится для премиума: абстрактные объекты, металл, стекло |
| [Shapefest](https://www.shapefest.com) | 160 000+ 3D-объектов |
| [Poly Pizza](https://poly.pizza) | Low-poly модели |
| [3dicons.co](https://3dicons.co) | Open-source 3D-иконки |
| [unDraw](https://undraw.co), [Storyset](https://storyset.com), [DrawKit](https://www.drawkit.com), [Humaaans](https://www.humaaans.com), [Open Peeps](https://www.openpeeps.com), [ManyPixels](https://www.manypixels.co/gallery), [Blush](https://blush.design) | Для не-люксовых проектов |
