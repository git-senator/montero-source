# Шрифты, положенные владельцем вручную

## Migha Display — Seniors Studio

Путь: `Migha Display/`
Что внутри: 96 статических `.otf` (Normal / Condensed / Semi Expanded / Expanded,
веса Thin…Black, варианты CNTR и Slant) плюс переменный `Migha_Variable.ttf`
с осями `wght` 100–900, `wdth` 1–10, `CNTR` 1–10, `slnt` −12…0.

**КИРИЛЛИЦЫ НЕТ.** Проверено по таблице символов всех 96 начертаний и
переменного файла: 182–184 глифа, только латиница. Русский текст этим
шрифтом набрать нельзя — браузер молча подменит его системным.

Годится для: латинских языков сайта (английский, португальский, испанский,
итальянский), монограмм, слов вроде WhatsApp и Latin America.

В файлах нет полей лицензии (name ID 13/14 пустые) и в архиве не было
текстового файла с условиями. Перед коммерческим применением условия
нужно взять у автора.

## Как подключать

Файлы лежат вне сайта намеренно: это склад, а не рабочая папка. Чтобы
применить, скопируйте нужное начертание в `v2/assets/fonts/`, переведите
в woff2 и пропишите `@font-face`. Для артефакта `build.py` должен вшить
файл как data-URI — внешние шрифты, кроме Google Fonts, там блокируются.
