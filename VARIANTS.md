## Что общее у всех вариантов

- Одна страница, адрес никогда не меняется — `history` не трогается намеренно.
- Разделы: HERO · SERVICES · DESTINATIONS (5) · CONCIERGE · REQUEST · FINAL · FOOTER.
- Компонент формы `assets/js/request-form.js` одинаковый: одна схема полей строит
  разметку, валидацию и payload. Бэкенд подключается заменой транспорта в `app.js`.
- Контакты: +55 11 96842 2222 · https://t.me/ROSSA_CO · wa.me/5511968422222
- Ни одной внешней зависимости, кроме Google Fonts. Ни GSAP, ни React, ни CDN.
- Фото нет — вместо них световые подложки. Слоты описаны в `assets/img/README.txt`.

## Языки (вариант 2)

**Основа — русский, и он живёт в самой разметке**, а не в словаре. Переводы
на английский, португальский, испанский и итальянский лежат в
`v2/assets/js/i18n.js`.

Почему так: исходный текст должен быть в одном месте. Правите строку в
`index.html` — русский меняется сразу, никакой второй копии, которая может
отстать. Словарь при этом хранит ровно четыре языка, а не пять.

Разметка размечена пятью атрибутами:

| Атрибут | Что подменяется |
|---|---|
| `data-i18n` | `textContent` |
| `data-i18n-html` | `innerHTML` — там, где внутри теги |
| `data-i18n-ph` | `placeholder` |
| `data-i18n-content` | `content` — описание страницы в `<meta>` |
| `data-i18n-aria` | `aria-label` — подписи для скринридеров |

Услуги, направления и шаги лежат массивами: `svc.7.tag` читается как
`svc[7][1]`, порядок полей одинаков во всех языках.

Как добавить язык: дописать блок `DICT.xx` в `i18n.js` и строку в `LANGS`.
Плашка выбора и переключатель в шапке соберутся сами.

**Значения, уходящие в заявку, всегда английские.** В списке услуг посетитель
видит «Аренда вертолёта», а в заявку падает `Helicopter Charter` — иначе
заявки превратились бы в кашу из пяти языков. Переводится только подпись.

## Чем отличается вариант 2

| | Вариант 1 | Вариант 2 |
|---|---|---|
| Палитра | уголь, изумруд, слоновая кость, шампань | чёрный с красным смещением, алый, вольфрамовое золото, пергамент |
| Заголовки | Bodoni Moda | Cormorant Garamond |
| Капитель | — | Cinzel (римские прописные, нумерация разделов) |
| Текст | Jost | Barlow + Commissioner на кириллицу |
| Услуги | гармошка на всю ширину | реестр слева + прилипшая сцена справа; на мобильном — гармошка |
| Направления | сетка | полосы во весь экран с освещённой пластиной под снимок |
| Фактура | — | зерно плёнки поверх всей страницы, виньетки, нити света в первом экране |
| Языки | — | пять, основа русская, плашка выбора при первом заходе |

Про шрифты и кириллицу: в Cinzel и Barlow кириллицы нет. Cinzel подменяется
на Cormorant Garamond — то есть на кириллице капитель и заголовки говорят
одной гарнитурой, это сознательно. Barlow без пары уезжал в системный
Segoe UI, поэтому рядом с ним стоит Commissioner: латиница не изменилась
ни на пиксель, кириллица перестала выпадать из набора.

## Сборка

```
python build.py        # вариант 1 → dist/
python build.py v2     # вариант 2 → v2/dist/
```

На выходе два файла: `index.html` — полный документ для хостинга,
`artifact.html` — без обвязки, для публикации артефактом.

## Публикация

Живой адрес: **https://git-senator.github.io/la-concierge/**
Репозиторий: https://github.com/git-senator/la-concierge (публичный)

Папка `_publish/` — то, что залито. Обновить после правок в `v2/`:

```
cp v2/index.html _publish/ && cp -r v2/assets _publish/ && rm -f _publish/assets/img/hero.mp4
cd _publish && git add -A && git commit -m "правки" && git push
```

Через минуту GitHub Pages пересоберёт страницу по тому же адресу.
